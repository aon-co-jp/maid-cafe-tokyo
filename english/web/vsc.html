🎀 maid-cafe-vsc (VS Code 拡張)

日本語

コードに「好きな色」をつけて、そのままAIに質問できる、VS Code の拡張機能です。

  1. VS Code でコードをマウスやカーソルで選ぶ。
  2. 好きな色で印をつける(右クリック、または Ctrl+Alt+M)。
  3. 「この色の部分について」と質問すると、同じ色の範囲がまとめてAIに届きます。

たとえば「赤=バグが疑わしい所」「青=意味が分からない所」のように、色で分けて聞けます。

使えるAI

  • 無料: aruaru-search + aruaru-llm(このサイトのAI)。
  • 有料: ChatGPT・Gemini・DeepSeek・Grok・Claude は、ご自身で各社と契約して、ご自分のAPIキーを設定してお使いください。キーはお使いのVS Codeの中だけに保管されます。私たちは料金や決済を扱いません。

安心のしくみ

  • 送る前に、パスワード・鍵・トークンらしい文字を自動で伏せます。
  • 何を送るかを毎回確認できます(設定でオフにもできます)。
  • 選んだ範囲だけが送られ、プロジェクト全体は送りません。

拡張のコマンドから、maid-cafe.tokyo の質問と回答とプログラミング教室をすぐ開けます。

English

A VS Code extension that lets you mark code with any colour and ask an AI about it right away.

  1. Select code in VS Code with the mouse or cursor.
  2. Mark it with a colour you like (right-click, or Ctrl+Alt+M).
  3. Ask a question about a colour: every range with that colour is sent to the AI together.

For example: red = "looks buggy", blue = "I do not understand this". Colours let you ask about each group separately.

Which AI

  • Free: aruaru-search + aruaru-llm (this site's AI).
  • Paid: ChatGPT, Gemini, DeepSeek, Grok and Claude — you sign up with each provider yourself and enter your own API key. The key stays inside your VS Code. We handle no billing or payments.

Safety

  • Passwords, keys and tokens in the code are masked automatically before sending.
  • You can confirm what is sent every time (switchable in settings).
  • Only the marked ranges are sent, never the whole project.

Learn while building from a job or project / arurau

A command opens arurau (audiocafe.tokyo), the IT engineer job and project matching page. Import freelance, dispatch or employee listings (a pasted URL, text, or an md/txt file) and work with the AI through requirements, a design draft, task breakdown, code generation and review, and debugging from a pasted error. A learning mode briefly explains why at each step. Names, contact details and rates are masked before sending. A URL is fetched only if you paste it, once, after you confirm.
